**Update: simple first screen for the bolus calculator, insulin bolus and QuickWizard**

The calculator now opens on a short screen. The full screen is one tick away, and its settings are remembered:

- **Bolus calculator (panel 1):** carbs, the usual Bread / Cake / Pizza meal type, and four checkboxes: use split boluses for FPU (unticked uses eCarbs), automatic fat and protein, walking soon, and Detailed settings.
- **Insulin bolus (panel 2):** a bolus from the Insulin dialog opens the same simple screen with "Insulin to give" and carbs. Entering carbs switches to the meal calculator.
- **QuickWizard editor (panel 3):** name, mode, carbs, meal type and the same checkboxes. Everything else is under Detailed settings and keeps the button's saved values.
- **Detailed settings:** ticking it shows the full screen, and unticking it returns to the simple one. The calculator always opens simple.
- **Remembered settings:** hidden settings still count. BG, TT, IOB, COB, trend and the FPU options start from the last confirmed calculation, and the automatic rules still apply on top.
- **Outlines:** the main input is outlined in the carbs colour, or the insulin colour in insulin-only mode.
